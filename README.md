# 🧠 AI Resume Analyzer

A full-stack AI-powered resume analysis platform designed with a
production-first mindset, explainability, and phase-based evolution.

## Repositories
- **Frontend** → `/frontend`
  - React, Vite, Tailwind CSS
  - Explainable UI for resume analysis, ATS simulation, and learning roadmaps

- **Backend** → `/backend`
  - Node.js, Express, LLMs, RAG, ATS simulation
  - Deterministic skill analysis with AI-powered explanations

## Current Status
- Phase 1–6: Complete
- Phase 7 (Embeddings & RAG): In progress

## Architecture Philosophy
- Frontend visualizes backend decisions (no duplicated logic)
- Backend follows Router → Controller → Service → Engine layering
- RAG and embeddings are toggleable to control cost

> Each folder contains its own detailed README with setup instructions.
