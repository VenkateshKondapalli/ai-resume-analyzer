## 1. POST `/analyze`

Analyzes resume against a job description. Primary endpoint used by the frontend dashboard.

### Request
**Headers**: `Content-Type: multipart/form-data` OR `application/json`

**JSON Body**:
```json
{
  "resumeText": "string (plain text resume, max 18k chars)",
  "jobDescription": "string (job requirements)"
}
```

**Multipart Form**:
- `resume`: Binary file (PDF; DOCX parser planned)
- `jobDescription`: String
- `resumeText`: (Optional string fallback)

### Success Response (`200 OK`)
```json
{
  "success": true,
  "result": {
    "resume_skills": ["Docker", "Node.js", "React"],
    "job_skills": ["Docker", "Express.js", "Kubernetes", "Node.js"],
    "matched_skills": ["Docker", "Node.js"],
    "partial_matched_skills": [],
    "missing_skills": ["Express.js", "Kubernetes"],
    "match_score": 50,
    "confidence_level": "Low",
    "explanation": "Human-readable feedback generated by Gemini explaining the 50% score...",
    "ats_simulation": {
      "ats_decision": "REJECT",
      "ats_reason": "Missing core ATS skills",
      "missing_core_skills": ["Express.js", "Kubernetes"],
      "missing_secondary_skills": []
    }
  }
}
```

### Error Responses
- `400 Bad Request`: `{"success": false, "error": "resumeText is required or upload a resume file"}`
- `503 Service Unavailable`: `{"error": "Model overloaded. Try again shortly.", "retry_after_seconds": 10}`
- `500 Internal Server Error`: `{"error": "<error message>"}`

## 2. POST `/analyze/roadmap`

Generates an on-demand milestone learning path for missing skills.

### Request
**Headers**: `Content-Type: application/json`

```json
{
  "missing_skills": ["Kubernetes", "Docker"],
  "role": "Backend Developer"
}
```
*Note: `role` is optional; defaults to `"Backend Developer"` if omitted.*

### Success Response (`200 OK`)
```json
{
  "success": true,
  "result": {
    "role": "Backend Developer",
    "missing_skills": ["Kubernetes", "Docker"],
    "roadmap": [
      {
        "skill": "Docker",
        "category": "DevOps",
        "estimated_effort": "1–2 weeks",
        "what_to_learn": [
          "Dockerfile commands",
          "Container networking and volumes",
          "Multi-stage builds"
        ],
        "project_ideas": [
          "Containerize a Node.js Express API and MongoDB database with Docker Compose"
        ],
        "learning_resources": [
          "Official Docker Documentation",
          "Docker for Beginners Tutorial"
        ]
      }
    ]
  }
}
```

### Error Responses
- `400 Bad Request`: `{"success": true, "error": "missing_skills must be a non-empty array"}`
- `503 Service Unavailable`: `{"error": "Model overloaded. Try again shortly.", "retry_after_seconds": 10}`
- `500 Internal Server Error`: `{"success": false, "error": "<error message>"}`

## 3. POST `/analyze/skill-knowledge`

Fetches RAG-augmented technical explanations for a specific skill.

### Request
**Headers**: `Content-Type: application/json`

```json
{
  "skill": "AWS"
}
```

### Success Response (`200 OK`)
```json
{
  "skill": "AWS",
  "explanation": "Amazon Web Services (AWS) is a cloud computing platform..."
}
```
*Frontend Contract: The client reads `res.explanation` directly (see `ResultCard.jsx`).*

### Error Responses
- `400 Bad Request`: `{"success": false, "error": "skill is required and must be a non-empty string"}`
- `503 Service Unavailable`: `{"success": false, "error": "Model overloaded. Try again shortly.", "retry_after_seconds": 10}`
- `500 Internal Server Error`: `{"success": false, "error": "<error message>"}`

## 4. POST `/ats/simulate`

Simulates ATS decision rules for an already-extracted text pairing without running LLM generation. (Not called by the frontend; available for decoupled backend consumers).

### Request
**Headers**: `Content-Type: application/json`

```json
{
  "resumeText": "string",
  "jobDescription": "string"
}
```

### Success Response (`200 OK`)
```json
{
  "success": true,
  "result": {
    "resume_skills": ["React"],
    "job_skills": ["React", "TypeScript"],
    "matched_skills": ["React"],
    "partial_matched_skills": [],
    "missing_skills": ["TypeScript"],
    "match_score": 50,
    "confidence_level": "Low",
    "jd_importance": {
      "total_similar_jds": 5,
      "core_skills": ["React", "TypeScript"],
      "secondary_skills": []
    },
    "ats_simulation": {
      "ats_decision": "REJECT",
      "ats_reason": "Missing core ATS skills",
      "missing_core_skills": ["TypeScript"],
      "missing_secondary_skills": []
    }
  }
}
```

### Error Responses
- `400 Bad Request`: `{"success": false, "error": "resumeText and jobDescription are required"}`
- `500 Internal Server Error`: `{"success": false, "error": "ATS simulation failed"}`
